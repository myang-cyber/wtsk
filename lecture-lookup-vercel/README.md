# 선택특강 조회 웹앱 — 설치 가이드

터미널 명령어 없이, 웹 화면 클릭만으로 설정할 수 있도록 안내해 드립니다.
전체 과정은 크게 3단계입니다.

1. Notion에 명단 데이터베이스 만들기
2. Notion과 연결할 "통합(Integration)" 발급받기
3. GitHub + Vercel로 배포하기

---

## 1단계. Notion 데이터베이스 만들기

1. Notion에서 새 페이지를 만들고, `/표` 또는 `/database`를 입력해 **데이터베이스(Table)**를 하나 생성합니다.
2. 아래 4개의 열(속성)을 정확히 이 이름으로 만듭니다. (띄어쓰기 없이 그대로)

   | 열 이름 | 속성 타입 |
   |---|---|
   | 이름 | 제목 (Title) — 데이터베이스 생성 시 기본으로 있는 열 |
   | 전화번호 | 텍스트 (Text) |
   | 교시 | 텍스트 (Text) — 없어도 되지만 있으면 표시됨 |
   | 선택특강 | 텍스트 (Text) |

   > ⚠️ **전화번호는 반드시 "텍스트" 타입으로 만들어 주세요.** Notion의 "전화번호" 타입이 아니라 일반 텍스트 타입이어야 합니다.

3. 참가자 명단을 이 표에 입력합니다. 한 사람이 여러 교시 특강을 신청했다면, 한 사람당 한 줄이 아니라 **줄을 나눠서** 각각 입력하면 됩니다.

   예시:

   | 이름 | 전화번호 | 교시 | 선택특강 |
   |---|---|---|---|
   | 홍길동 | 01012345678 | 1교시 | 시편과 그리스도 |
   | 홍길동 | 01012345678 | 2교시 | 구약의 그리스도 |

4. 앞으로 명단을 추가/수정할 때는 **이 Notion 표만 수정하면 됩니다.** 웹사이트에 즉시 반영되며, 별도 재배포가 필요 없습니다.

---

## 2단계. Notion 통합(Integration) 발급받기

1. 브라우저에서 [notion.so/my-integrations](https://www.notion.so/my-integrations) 로 이동합니다.
2. **"+ New integration"** 클릭
3. 이름은 아무거나 입력 (예: "선택특강 조회 앱"), 워크스페이스 선택 후 **Submit**
4. 생성된 화면에서 **"Internal Integration Secret"** 값을 복사해 둡니다. (`secret_`로 시작하는 긴 문자열) → 이 값이 나중에 `NOTION_API_KEY`가 됩니다.
5. 1단계에서 만든 데이터베이스 페이지로 돌아갑니다.
6. 데이터베이스 오른쪽 위 **`···`(더보기 메뉴)** → **"연결(Connections)"** → 방금 만든 통합("선택특강 조회 앱")을 검색해서 추가합니다.
7. 데이터베이스 페이지의 URL을 확인합니다. 아래처럼 생겼습니다.

   ```
   https://www.notion.so/워크스페이스이름/1234567890abcdef1234567890abcdef?v=...
   ```

   `1234567890abcdef1234567890abcdef` 부분(32자리 문자/숫자)이 **데이터베이스 ID**입니다. 이 값을 복사해 둡니다. → 나중에 `NOTION_DATABASE_ID`가 됩니다.

## 3단계. GitHub + Vercel로 배포하기

### 3-1. GitHub에 코드 올리기 (git 명령어 불필요)

1. [github.com](https://github.com)에 가입/로그인합니다.
2. 오른쪽 위 **"+"** → **"New repository"** 클릭
3. 이름은 아무거나 입력 (예: `lecture-lookup`) 후 **Create repository**
4. 생성된 저장소 화면에서 **"uploading an existing file"** 링크를 클릭합니다.
5. 이 폴더(`lecture-lookup-vercel`) 안의 파일/폴더 전체를 화면에 드래그 앤 드롭합니다. (폴더째로 끌어다 놓으면 구조가 그대로 유지됩니다 — 크롬/엣지 브라우저 권장)
6. 아래로 스크롤해서 **"Commit changes"** 클릭

### 3-2. Vercel로 배포하기

1. [vercel.com](https://vercel.com)에 가입/로그인합니다. (GitHub 계정으로 로그인하면 편합니다)
2. **"Add New..." → "Project"** 클릭
3. 방금 만든 GitHub 저장소(`lecture-lookup`)를 찾아 **Import** 클릭
4. **"Environment Variables"** 항목을 펼쳐서 아래 2개를 입력합니다.

   | Name | Value |
   |---|---|
   | `NOTION_API_KEY` | 2단계에서 복사한 `secret_...` 값 |
   | `NOTION_DATABASE_ID` | 2단계에서 복사한 32자리 데이터베이스 ID |

5. **Deploy** 클릭 → 1~2분 후 배포가 완료되고, `https://프로젝트이름.vercel.app` 형태의 링크가 생성됩니다.
6. 이 링크를 참가자들에게 공유하면 됩니다.

---

## 이후 명단을 수정하고 싶을 때

- **명단 추가/수정/삭제**: Notion 표만 수정하면 됩니다. 별도 재배포 불필요, 실시간 반영됩니다.
- **디자인이나 문구 수정**: 코드 수정이 필요하니 이런 요청은 다시 말씀해 주세요.

## 문제가 생기면

- 조회했는데 "일치하는 신청 내역을 찾을 수 없습니다"라고 나온다면 → Notion 표의 이름/전화번호 값에 오타나 공백이 없는지 확인해 주세요.
- "서버에 Notion 연동 정보가 설정되지 않았습니다"라고 나온다면 → Vercel의 Environment Variables 2개가 정확히 입력됐는지 확인해 주세요. (입력 후에는 Vercel 프로젝트의 "Redeploy"가 한 번 필요할 수 있습니다)
